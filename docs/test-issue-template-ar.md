الأولوية: **مانع للتست** إذا تعذر الدخول أو التسجيل أو فتح الحصة أو ظهرت بيانات أسرة أخرى؛
**عالية** إذا فُقد تغيير محفوظ أو تعذر إكمال خطوة رئيسية؛ **متوسطة** لمشكلة مربكة مع وجود حل بديل؛
**منخفضة** لصياغة أو محاذاة لا تمنع الإكمال.

في حالة فشل الصوت أو الفيديو، أضف حالة أذونات الكاميرا والمايك، الشبكة المستخدمة، وهل اشتغل الاتصال بعد إعادة الدخول.
وفي حالة فشل الحفظ، اذكر هل بقي التغيير ظاهرًا بعد تحديث الصفحة. لا تعتبر الخدمة الخارجية غير المهيأة عطلًا في الواجهة؛ سجّلها «غير مهيأة».
